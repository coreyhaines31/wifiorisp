# Contributing

Bug reports, ideas, and pull requests are welcome. Open an issue first for anything bigger than a small fix, so we can agree on the approach.

## Before you open a pull request

- Build with Xcode (see the README), run the tests, and run `swiftlint`.
- Keep each pull request to one change.
