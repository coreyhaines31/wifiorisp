Getting started with WiFi or ISP

Everything you need for the first few minutes, and answers to the questions people ask most.

By Corey Haines, maker of WiFi or ISP · Updated October 6, 2026

Install

Requires macOS 14 Sonoma or later. Download the DMG, open it, and drag WiFi or ISP to Applications. Or, with Homebrew: brew install --cask coreyhaines31/tap/wifiorisp. It's signed and notarized by Apple, and updates itself.

Install with Claude Code or Codex

Paste this into your coding agent and it will install and open the app for you.

Install the macOS app "WiFi or ISP" for me.
If Homebrew is installed (check with `command -v brew`), run:
  brew install --cask coreyhaines31/tap/wifiorisp
Otherwise, download and install the signed DMG:
  curl -fL -o /tmp/WiFiOrISP.dmg https://github.com/coreyhaines31/wifiorisp/releases/latest/download/WiFiOrISP.dmg
  hdiutil attach -nobrowse -quiet -mountpoint /tmp/wifiorisp-dmg /tmp/WiFiOrISP.dmg
  ditto "/tmp/wifiorisp-dmg/WiFi or ISP.app" "/Applications/WiFi or ISP.app"
  hdiutil detach -quiet /tmp/wifiorisp-dmg
Then open it with: open -a "WiFi or ISP"
It's a menu bar app with no Dock icon. Tell me to look for the small router
icon near the clock, and that its welcome window asks about Location access
(only used to show the Wi-Fi network name) and opening at login.
Finally, run `wifiorisp status` (Homebrew puts it on the PATH; otherwise it's
"/Applications/WiFi or ISP.app/Contents/MacOS/wifiorisp") and tell me what it says.

Want to build it from source instead?

Clone https://github.com/coreyhaines31/wifiorisp and build it from source.
It needs Xcode 16 or later. Install XcodeGen and SwiftLint with Homebrew if
they're missing, then from the repo root run Scripts/run-local.sh, which builds
the app signed to run locally (no Apple Developer account) and opens it.
Then run the tests with: cd Packages/WiFiOrISPCore && swift test
Read CONTRIBUTING.md before changing any code.

Command line, for you and your AI agent

The wifiorisp command asks the app from Terminal, so you, a script, or Claude Code or Codex can find out what's wrong with the internet without clicking anything. Homebrew puts it on your PATH. If you installed from the DMG, link it once: sudo ln -sf "/Applications/WiFi or ISP.app/Contents/MacOS/wifiorisp" /usr/local/bin/wifiorisp

wifiorisp status              # the verdict, the numbers behind it, and what to do next
wifiorisp watch               # a line after every measurement, until Ctrl-C
wifiorisp lag                 # lag under load, and where it builds up
wifiorisp speed               # download and upload speed, from M-Lab
wifiorisp history --since 24h # timings, slow spells, drops, and tests from the log
wifiorisp report --since 7d   # the report to send your ISP

Add --json to any of them for output an agent can read: each next step comes with a link to a guide or a command to run. status exits with 2 when it finds a problem. The commands that ask the app open it in the background if it isn't running.

Ask your agent in plain words, like “My Zoom calls keep freezing. Use the wifiorisp command to find out whether it's my Wi-Fi or my ISP, and tell me what to fix.” Or add this to your CLAUDE.md or AGENTS.md:

When I say the internet is slow, laggy, or dropping, run `wifiorisp status --json`
to see whether it's my Wi-Fi or my ISP, and follow its nextSteps. Run `wifiorisp lag`
when calls or games stutter, `wifiorisp speed` to compare with my plan, and
`wifiorisp report` when I need evidence for my ISP.

Your first two minutes

  1. Open it from Applications. There's no Dock icon or main window. It lives in the menu bar, as a small router icon near the clock.
  2. Answer the welcome window. Allow Location access if you want to see your Wi-Fi network's name (macOS treats it as location data; the app never reads your location). Leave “Open at login” on so it keeps watching.
  3. Allow local network access. macOS 15 and later ask once; the app needs it to time your router.
  4. Allow notifications if you want them. They tell you about drops and weak connections.
  5. Give it 30 seconds. The first verdict needs a few measurements.

Can't see the icon? On MacBooks with a notch, a full menu bar hides icons behind it. Hold ⌘ and drag other icons aside, or quit a few menu bar apps.

Reading the menu

The router icon's three lights show your Wi-Fi signal. When something is slow, the lights go dark and a word appears beside it: WiFi, Router, or ISP. A slash means you're not connected to any network.

You seeIt means
Fine: WiFi and ISP both OKYour router and the internet both answer quickly.
Slow: weak WiFi signalEven your router is slow, and the signal is weak.
Slow: WiFi or router, not ISPStrong signal, but the router is slow: a busy channel, interference, or an overloaded router.
Slow: ISP, not WiFiYour router is quick; the internet past it isn't.
Offline: ISP is down, WiFi is fineYour router answers, nothing past it does.
Offline: can't reach your routerYour Mac lost the router.

Under the verdict, What to do lists the next steps for your situation. Click one to open the right guide, start a test, or export a report for your provider. How the verdict works.

Troubleshooting

It says “Unknown network”

Location access isn't allowed. Click Show Network Name… in the menu, or turn on WiFi or ISP in System Settings → Privacy & Security → Location Services.

The router “doesn't answer probes”

Some routers ignore the probes; the verdict then relies on your signal and the internet's timing. If that's new, check System Settings → Privacy & Security → Local Network and make sure WiFi or ISP is on.

It says “Wired”

Your Mac is using Ethernet, so there's no Wi-Fi signal to show. Your router and the internet are still measured.

I'm on a VPN

It still times the router of the Wi-Fi network underneath. It skips identifying your provider, which would name the VPN.

A speed or lag test failed

Both need a working internet connection. If it's down, the verdict will say so.

Privacy

No analytics and no account. History stays on your Mac. In the background, the app times a handshake to your router and to two internet addresses every few seconds (no data is sent in them), and asks Cloudflare once per network which provider you're on. Speed and lag tests run only when you start them. The full method.

Uninstall

Quit it from its menu and drag it to the Trash. If it opens at login, turn that off first in its Settings, or in System Settings → General → Login Items. With Homebrew, brew uninstall --zap --cask wifiorisp also removes its history and settings.
